about=KADAS Albireo 2 plugin providing unified access to 8 satellite imagery sources through a standardized STAC-inspired connector architecture. Production-ready connectors: (1) ICEYE SAR Open Data - 3 collections, 196 items, global coverage, all-weather/day-night acquisition, (2) Umbra SAR Open Data - up to 16cm resolution SAR, recursive STAC catalog (year/month/item), GEC/SICD/SIDD/CPHD products, (3) Capella SAR Open Data - ~1000 SAR images organized by product/mode/use-case/capital/datetime/IEEE, X-band radar with GEO/GEC/SLC/SICD/SIDD formats, (4) Maxar Open Data (Vantor STAC) - 55+ disaster event collections, sub-meter optical imagery for emergency response and damage assessment, (5) Copernicus Dataspace STAC - Sentinel-1/2/3/5P via OAuth2 and STAC API 1.1.0. Experimental connectors: Planet Labs (PSScene, SkySatScene), NASA EarthData (CMR/granule search), OneAtlas (Airbus). Architecture: unified search_unified() interface across all connectors inspired by STAC-Atlas patterns, lightweight STAC item validation, correct open-data/auth-required capability gating, ConnectorManager with parallel collection loading (5-worker ThreadPoolExecutor) and 5-minute TTL cache. Features: interactive map-based footprint selection with bidirectional table sync, Cloud-Optimized GeoTIFF (COG) loading via GDAL vsicurl, advanced search filters (bbox, date range, cloud cover), comprehensive logging system, QgsNetworkAccessManager for SSL/proxy handling. All dependencies bundled for one-click installation.
